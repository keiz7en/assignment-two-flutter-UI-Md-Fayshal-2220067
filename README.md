# Assignment 2 — Flutter UI

Four Flutter pages: **Home, Tasks, Profile, Progress**, following the reference screens embedded in the supplied `Assignment 2 _ Flutter UI.fig` file. Screens are built with Flutter widgets, not screenshot backgrounds. Navigation uses a `PageView` controlled by a `PageController`; bottom tab taps animate between pages. Swipe navigation is disabled for the required click-only demonstration.

## Run on Windows

Install Flutter and Android Studio with Android SDK. Connect an Android phone with USB debugging enabled, or start an emulator.

1. Extract the ZIP and open this folder.
2. Double-click `SETUP_WINDOWS.bat`. It creates the SDK-specific native scaffolding, resolves dependencies, analyzes the code and runs the tests.
3. Run `flutter run` in this folder.

Or use a terminal:

```sh
flutter doctor
flutter create --platforms=android .
flutter pub get
flutter analyze
flutter test
flutter run
```

Use Flutter 3.35 or newer. The SDK is not bundled. The native Gradle wrapper/bootstrap files must be generated by `flutter create` before building or submitting the repository. To add iOS on a Mac, use `flutter create --platforms=ios .`.

## Student details

The supplied name, ID and institutional email are already entered in `lib/student_details.dart`. Avatar initials are generated automatically. **Phone, Department and Semester were not supplied**: they show `Tap to add` rather than fabricated information. Enter the real values in that file before recording and submitting. You can also use Profile → settings or tap a profile field to try editing the app.

Profile edits, task additions, reminder preferences and completion changes last for the current app session. Restarting restores the source defaults. This assignment UI does not contact a server or send student details over the network. Notification and reminder controls demonstrate preferences; they do not schedule operating-system notifications.

## Implemented interactions

- Bottom tabs open all four pages using PageController.
- Home: select a calendar day, open tasks, show notifications and timetable.
- Tasks: search by title/course, filter by date (remove date chip to reset), complete tasks, add a task with course/priority/due date and time.
- Profile: edit fields, notification toggle, study reminder time picker, working dark theme.
- Progress: week navigation and calendar selection; task completion updates the sample current-week total.
- The study durations, streak and course percentages use the demonstration values in the Figma reference. No real study tracking or authentication was requested. Log out explains the local profile mode.
